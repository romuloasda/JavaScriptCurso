Regra de ouro da navegação de elementos

Sempre que quiser navegar apenas entre tags HTML (ignorando espaços vazios), procure pelas propriedades que contêm a palavra Element:

  1. parentElement sobe para a tag pai.
  2. children: lista de todas as tags filhas (como um array).
  3. firstElementChild: primeira tag.
  4. filha.lastElementChild: última tag.
  5. filha.nextElementSibling: tag irmã que vem depois.
  6. previousElementSibling: tag irmã que vem antes.
